# 前端原型对齐与公司 Logo 替换

## 讨论主题

将当前 Vue 管理端的工作台、招聘助手、调用审计和基础配置四个页面重新对齐 `Prototype/AI 能力中台.html`，并使用用户提供、原型内已嵌入的公司 Logo。

## 关键结论

- 原先页面复用了真实业务接口，但视觉骨架偏离原型，不能继续以大幅黑色横幅版式为基准。
- 前端以原型 V2 的固定侧栏、顶栏、指标卡、场景卡、步骤条、深色结果区和表格样式作为后续视觉基准。
- 招聘助手继续保留 PDF/DOCX 上传和粘贴文本两种输入方式，不因视觉还原移除已经完成的真实功能。
- 基础配置保持只读。即使原型存在保存按钮和 API Key 输入框，也不向浏览器返回、展示或修改真实 Key。

## 完成修改

- 从原型内嵌资源提取透明 PNG 公司 Logo，保存到 `frontend/src/assets/company-logo.png`。
- 重建 `frontend/src/App.vue` 的侧栏、分组导航、管理员区、服务状态与通知顶栏。
- 重建工作台为四项运行指标、业务场景、后续场景和运行概览布局。
- 将招聘助手改为原型式三段流程条、双栏工作区与深色结构化结果区，并保留上传、文本、示例、清空、复制和真实接口调用。
- 将调用审计改为指标卡、导出、能力/状态/Request ID 筛选和原型式表格。
- 将基础配置改为两栏只读配置与调用策略布局，并保留数据安全和访问控制信息。

## 错误与处理

- 第一次提取 Logo 时按错误的 HTML 属性顺序匹配，未找到资源；调整为不依赖属性顺序的匹配后成功提取。
