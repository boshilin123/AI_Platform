# 安全设计

## 凭据

- `GPTSAPI_API_KEY` 只通过后端环境变量或部署 Secret 注入。
- API Key 不写入数据库、前端、Git、Dockerfile、响应和普通日志。
- 配置接口仅暴露是否已配置。

## 调用鉴权

本地开发允许不配置 `INTERNAL_API_TOKEN`。测试和生产环境必须配置，并由受控调用方通过 `X-Internal-Token` 传递。后续接入公司统一身份系统后替换共享 Token。

## 简历隐私

- 请求体不进入访问日志。
- 审计只保存内容长度和 SHA-256。
- 第一阶段不持久化简历或招聘结果。
- 错误信息不得包含简历片段和提示词。

## 公开仓库

- `.env`、数据库文件、构建产物必须忽略。
- 示例配置使用空值或占位符。
- 合并前检查 `sk-`、`Bearer`、密码和私钥模式。
