# 第一阶段需求

## 建设目标

使用现有 OpenAI 兼容 API Key 建设公司内部统一 AI 服务。业务系统只调用中台业务接口，不接触真实上游 Key。

## 功能范围

### 基础调用层

- 非流式 Chat Completions。
- 流式调用基础能力。
- 连接、读取和流空闲超时。
- 错误分类和最多两次有限重试。
- Token 用量汇总。
- 业务请求与上游调用审计。

### AI 能力层

- 信息提取。
- 评价分析。
- 内容生成。
- 结构化 JSON 输出与校验。

### 招聘场景

- 简历解析。
- 岗位匹配与初筛。
- 面试题生成。

## 非功能要求

- 不泄漏上游 API Key。
- 默认不保存完整简历和提示词。
- 每个错误返回稳定错误码和 requestId。
- 本地可在 mock 模式下独立运行。
- 模块可测试，前后端可以分别构建。
